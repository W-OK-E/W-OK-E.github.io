Quaternions are that one piece of math that have always bothered me, and so today I set out to actually fully understand the concept behind them and to understand in what specific cases would be replace Matrices with Quaternions and vice versa.

So a rotation matrix is simply a linear transformation - You have a vector and then the transformation is essentially in such a way that ensures the length of the vector is preserved (in pure rotation) and if there are two or more vectors undergoing the same transformation, the angle between the two vectors is also preserved. Now we will limit ourselves to rotation matrices in 3-dimensions, but ofcourse you can imagine rotating a vector in an arbitrary number of dimensions. So in 3-dimensions, we have a 3x3 rotation matrix. An important little detail that we must keep in mind here is that the when talking about pure rotation - we don't want any scaling to happen - and if you remember it, when a vector is multiplied by a matrix - the amount by which the vector is scaled depends on the deteminant of the matrix. So, for pure rotation, the determinant needs to be 1.

So to sum it up:
1. Rotation is a "Linear" transformation (yes, let that sink in).
2. We don't want the vector to be scaled by any factor (length is preserved) hence determinant needs to be 1
