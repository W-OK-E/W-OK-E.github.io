Rigging is the step where you turn a mesh - that is made up of vertices etc. into something that can be articulated and animated. For 3D Reconstruction, one way to think about it is:

Images ->  3D Reconstruction -> Static Mesh -> Rigging -> Skeleton + SKinning Weights -> Pose and animate the mesh.

In a usual mesh that is made out of vertices etc. there is no inherent sense of saying - which parts can rotate about which ones, you get vertices, faces, texture, maybe normals. But the mesh may not know what parts correspond to what anatomy etc.

A rig usually has two main components:

1. SKeleton/bones
- A heirarchy of joints or bones is placed inside the mesh - is it safer to compare this with the kinematic tree that we have seen earlier?

2. Skinning weights
- Every mesh vertex gets weights saying how much the joints next to it influence it and so on.

3. Then, under standard linear blend skinning, the posed vertex is approximately the weighted sum of the transformation induced by each of the joints on the given vertex. That is the core mathematical Idea.

4. In case of our parametric model it is the pose parameters that controls the rigging.

Note the difference here however:

Rigging usually means defining the skeleon and deformation structure. Skinning is the process of conencting the mesh to that skeleton via weights. Posing means assigning specific joint transformations. Animation means varying these poses over time.

So Rigging means defining the skeleton. Skinning is the process of connecting the mesh to that skeletong via weights. Posing means assigning specific joint transformations. Animation means varying these poses over time. There are usually two ways to do reconstruction:
You reconstruct the mesh first then apply rigging, via auto-rigging or skeleton fitting. Or we can directly reconstruct using an already-rigged parametric template (VAREN etc.) which is much more stable if anatomy is the crucial point to focus on.


In our case, we are not reconstructing an arbitrary mesh and then figuring out the rigging step, we already sort of know the rig from VAREN and are estimating the parameters that deform and articulate it. In that setting, the reconstruction problem becomes much more constrained.


## Basics of inpainting:

During inpainting, when the topology is same, we only generate one UV map or UV atlas - UV atlas is one flattened out pattern which tells you where the vertices on the mesh fall on the flattened out texture.
- So think of it like this, every vertex on the mesh gets assigned a UV coordinate so that the same canonical atlas can be mapped onto any given mesh.
- Another Question here is that the okay the vertices have been handled but what about the rest of the points on the mesh? Where do they go? What decides that? It's simple - just interpolation between vertices.
